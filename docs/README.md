# Documentation

The lab notebooks link directly to the documentation needed for each activity.

- [ABCD Study naming convention](https://docs.abcdstudy.org/latest/documentation/curation/naming.html)
- [ABCD substance-use documentation](https://docs.abcdstudy.org/latest/documentation/non_imaging/su.html)
- [DEAP Data Dictionary](https://abcd.deapscience.com/#/my-datasets/create-dataset)

DEAP and official ABCD documentation are the sources of truth for variable wording and metadata. The CSV files in this repository are synthetic instructional data.
