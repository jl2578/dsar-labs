# Synthetic dataset groups

Each folder contains an independent synthetic sample used by the listed labs.

- `labs_01_03/`: Labs 1–3
- `labs_04_05/`: Labs 4–5
- `labs_06_07/`: Labs 6–7
- `labs_08_09/`: Labs 8–9

The groups may share ABCD-style structures and instructional assumptions, but they do not contain the same participants. Do not link records across dataset groups.
